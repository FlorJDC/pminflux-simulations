# papers/

Aquí va el material de referencia del objetivo actual: el/los paper(s) a reproducir, una
especificación, la descripción de un dataset. Un subdirectorio por fuente es un buen default
(p. ej. `papers/2306.16221/2306.16221.pdf`), para que `OBJECTIVE.md` apunte a una ruta estable.

No es código ni entregable: es solo lo que el equipo tiene permitido leer.
